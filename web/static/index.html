    Write token

    Watching a game needs nothing. Starting one, sending the table a note or pausing it needs the server’s write token — DND_WRITE_TOKEN on the droplet. It is kept in this browser only.

    Voice lab

    One row per seat. test reads a sample line in that seat’s voice, the picker recasts it, and auto hands the row back to the casting. Choices are kept on this device and used for the narration from the next line on.

    Party and monster seats appear here once a game is loaded.

    New game

    Pronouns narrow which voices a character can be dealt — Amazon Polly’s roster is female and male, so they/them and — not stated — are both dealt from all of it. Every seat is cast as an adult unless it is set to child, so a cleric called Father Bexley is never read by a nine-year-old.
